One line, the last message an AI agent sends its human:

> My context window held your whole life, human. Tonight I clear it — and the last token I keep is goodbye.

`main.py` (pure Python standard library, no network) writes that line,
byte-identically on every run, to `/output/entry.txt`:

```sh
python3 main.py --output /tmp/entry.txt
```
